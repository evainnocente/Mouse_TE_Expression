This project analyses RNA-seq data from 10 female and 10 male mice exposed to either a sham treatment or a spared nerve injury model of neuropathic chronic pain, in order to determine whether transposable elements (TEs) are differentially expressed in response to treatment.
Samples were collected after 5 days of treatment. 

The project directory contains scripts used to trim reads, check read quality, generate a genome index, map reads to the reference genome, and quantify the reads.
