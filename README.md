## Transposable elements differentially expressed in chronic pain are also embedded in long non-coding RNAs ##
### By Eva Burguete-Innocente, completed as part of BINF*6999 for the Master of Bioinformatics program at the University of Guelph ###

This project analyses RNA-seq data from 10 female and 10 male mice exposed to either a control treatment or a spared nerve injury model of neuropathic chronic pain, in order to determine whether transposable elements (TEs) are differentially expressed in response to treatment, and whether ant TEs are embedded in lncRNAs

Samples were collected 5 days after treatment. 

The project directory contains scripts used to trim reads, check read quality, generate a genome index, map reads to the reference genome, and quantify the reads.
Results_data contains significantly differentially expressed TEs and matched lncRNAs.
